# 블루 레코드 캐릭터 위키

## GitHub Pages에 올리기
이 폴더의 **내용물**을 GitHub 저장소의 루트에 올립니다. 저장소의 Settings → Pages에서 해당 브랜치와 /(root)를 선택합니다. 별도 빌드가 필요하지 않습니다.

## 캐릭터 추가
characters.json의 배열에 기존 항목을 복사해 고유한 id, name, image, html을 바꿉니다. tag는 선택입니다. 마지막 항목 뒤에는 쉼표를 넣지 않습니다.

```json
{"id":"char39","name":"새 캐릭터","image":"images/char39.png","html":"charcons/char39.html","tag":"SV"}
```

charcons/char2.html을 복사해 새 문서 파일을 만들고 제목, 이름, 이미지, 본문을 수정합니다. 이미지 파일은 images에 넣습니다. 문서 안에서는 ../images/char39.png처럼 경로 앞에 ../를 붙입니다. 목록과 개별 문서의 이름·이미지는 각각 수정해야 합니다. 기존 설정 내용이 제공된 라구스 문서는 원문을 유지했으며 나머지 문서는 빈 항목을 제공합니다.

검색은 전체 JSON의 이름에 적용되며 한 페이지에 50명씩 표시됩니다. 주소에 검색어와 페이지가 남아 뒤로 가기로 목록 상태를 복원할 수 있습니다. 이미지는 지연 로딩하고 읽지 못하면 기본 이미지로 대체합니다. 외부 이미지 주소는 원본을 사용하므로 만료되면 로컬 이미지로 교체하세요.

## 로컬 확인
JSON을 읽으므로 HTML을 더블클릭하는 대신 웹 서버로 확인합니다. Python이 설치되어 있으면 이 폴더에서 `python -m http.server 8000` 실행 후 http://localhost:8000 에 접속합니다.


## 전신 이미지 (2300 × 2600px)
characters.json의 fullImage에 전신 이미지 경로를 넣습니다. 예: "fullImage": "images/char2-full.png". image는 목록용 썸네일, fullImage는 문서용 전신 이미지입니다. 2300×2600px 원본을 준비해 images 폴더에 넣으세요. 화면에서는 23:26 비율로 축소하며 그림을 자르거나 늘리지 않습니다. 기존 라구스 원본 이미지의 실제 해상도를 바꾸지는 않았습니다. 외부 주소가 만료되면 준비 중 이미지로 표시됩니다.

문서의 data-character 속성을 JSON의 id와 맞추면 기본 정보의 이름·분류, 전신 이미지, 관련 캐릭터, 다음 캐릭터 링크가 JSON에 맞춰 표시됩니다. 새 문서는 char2.html을 복사하고 data-character, title, h1, 본문을 수정하세요. 같은 tag를 가진 캐릭터가 관련 문서에 표시됩니다. 마지막 캐릭터에서는 첫 캐릭터로 순환합니다.

복구한 기능: 관련 문서 접기·펼치기, 전신·갤러리 이미지 확대(닫기 버튼·배경 클릭·Esc), 다음 캐릭터 이동, 상세 목차, 맨 위로 이동. 검색·50명 단위 페이지 이동은 유지합니다. 포트폴리오 메뉴는 추가하지 않았습니다.


## 캐릭터 메인 컬러와 태그
각 캐릭터의 mainColor에 #RRGGBB 형식의 색을 입력하세요. 예: "mainColor": "#EF6471". 기본값은 파란색 #82adff이며 비어 있거나 잘못된 값도 기본 파랑으로 표시됩니다.

mainColor는 해당 캐릭터 위키의 제목 포인트, 전신 영역 테두리, 프로필 상단 선, 본문 제목의 왼쪽 선, 다음 캐릭터 버튼 등에 적용됩니다. 모든 캐릭터의 목록 이미지 배경·프로필 바탕·본문 바탕은 동일합니다. 사이트 공통 로고·검색·페이지 이동은 파란색을 사용합니다.

태그는 mainColor와 별개입니다. 원본 색상(SV #ffb3b3, DEE #c4a8e0, SF #a8c8ff, CC #888, TC #ccc)은 태그 배지에만 사용합니다.
